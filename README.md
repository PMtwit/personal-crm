# Личная CRM

Приложение, где я веду контакты людей, которых знаю лично: кто это, откуда знакомы, телефон и почта, о чём договорились. Идея и главный сценарий — в [specs/01-продуктовая-идея.md](specs/01-продуктовая-идея.md).

## Что нужно установить

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) — в нём работает база данных
- Node.js 24 (LTS) и pnpm — ставятся через Homebrew:

  ```
  brew install node@24 pnpm
  ```

## Первый запуск базы данных

1. Создайте файл настроек из шаблона:

   ```
   cp .env.example .env
   ```

2. Откройте `.env` и заполните значения. Пароль можно сгенерировать командой `openssl rand -hex 24`. В `DATABASE_URL` подставьте те же имя пользователя, пароль и имя базы.

3. Запустите базу:

   ```
   docker compose up -d --wait
   ```

## Проверить, что база работает

```
docker compose ps
```

У `personal-crm-db-1` должен быть статус `(healthy)` и адрес `127.0.0.1:5432`.

Подключиться к базе и узнать её версию:

```
docker compose exec db sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -c "select version();"'
```

## Остановить и запустить снова

- Остановить: `docker compose stop`
- Запустить: `docker compose up -d --wait`

База запускается сама вместе с Docker Desktop.

## Важно про данные

- Все контакты хранятся внутри Docker, в томе `personal-crm_pgdata`
- `docker compose down -v` **удаляет все данные без возможности восстановления**. Обычные `docker compose stop` и `docker compose down` данные не трогают
- База доступна только с этого компьютера — из локальной сети к ней подключиться нельзя
- `.env` с паролем не попадает в git. В git лежит только `.env.example` без значений

## Приложение

### Первый запуск

Все команды — в папке проекта, база должна быть запущена (см. выше).

1. Установить библиотеки:

   ```
   pnpm install
   ```

2. Создать таблицы в базе:

   ```
   pnpm db:migrate
   ```

3. Наполнить базу тестовыми данными — 1000 вымышленных контактов с заметками (по желанию):

   ```
   pnpm db:seed
   ```

   Команда срабатывает только на пустой базе. Если в ней уже есть хотя бы один контакт, она ничего не добавит и ничего не изменит. Почты у тестовых контактов — на служебных доменах `example.com`, `example.org`, `example.net`, поэтому письмо по ним никуда не уйдёт.

### Запустить

```
pnpm build
pnpm start
```

Откройте в браузере http://localhost:3000. Остановить — `Ctrl+C` в окне терминала, где запущено приложение.

`pnpm build` нужен после каждого обновления кода. Если вы меняете код и хотите сразу видеть изменения, вместо этих двух команд запустите `pnpm dev`: так удобнее разрабатывать, но приложение работает медленнее.

Приложение открывается только на этом компьютере: из локальной сети, например с телефона, его не видно. Входа по паролю в приложении нет, поэтому так безопаснее.

### Что умеет

- Главная страница — все контакты по алфавиту, с разбивкой по буквам
- Поиск по имени — список фильтруется во время набора. Регистр не важен, «ё» и «е» считаются одной буквой, слова можно вводить в любом порядке: «петров иван» найдёт «Иван Петров»
- «Добавить контакт» — имя (обязательно), кто это, откуда знакомы, телефон, почта
- Карточка контакта — все поля, кнопка «Изменить» и заметки. Новая заметка сохраняется кнопкой «Добавить заметку» или сочетанием ⌘ + Enter. Каждая заметка хранится отдельно, с датой и временем, новые — сверху

### Проверить, что всё работает

Автотест проходит главный сценарий из спеки: открыть список → добавить контакт → найти по имени → дописать заметку → проверить, что всё сохранилось, в том числе при открытии в другом браузере.

```
pnpm test:e2e
```

Тест работает с отдельной базой `personal_crm_test` и запускает своё приложение на порту 3100, поэтому ваши контакты не трогает и запущенному приложению не мешает. Для теста нужен установленный Google Chrome. При каждом запуске тестовая база очищается и заполняется заново.

### Если что-то пошло не так

- На странице «Не получилось загрузить данные» — не запущена база. Откройте Docker Desktop и выполните `docker compose up -d --wait`
- `Port 3000 is in use` — приложение уже запущено в другом окне терминала. Откройте http://localhost:3000 или остановите то приложение
