# Макеты «Пора связаться»

Смотреть макеты - на холсте: https://claude.ai/artifact/L1sKjLtG2PY5X9uhKmWR9D

На холсте кнопки работают: наведите на экран и нажмите Play. Файлы в этой папке - исходники тех же экранов. Отдельно в браузере они не открываются, им нужен холст. По ним видны точные размеры, отступы, цвета и тексты.

| Файл | Экран |
|---|---|
| `Main.dc.html` | Главная на телефоне: блок «Пора связаться», кнопки «Уже», «Показать всех (12)» / «Свернуть» |
| `Home-Desktop.dc.html` | Главная на компьютере: то же, кнопки «Уже связался» |
| `Note-Phone.dc.html` | Телефон: окно «Новая заметка» сразу после нажатия «Уже», в поле «Связался» |
| `Note-Desktop.dc.html` | Компьютер: то же окно после «Уже связался» |
| `Card-Phone.dc.html` | Карточка на телефоне: раздел «Как часто общаться» и строка срока |
| `Card-Desktop.dc.html` | Карточка на компьютере |
| `Frequency-States.dc.html` | Все состояния раздела «Как часто общаться»: не задано, срок впереди, срок в следующем году, срок подошёл, «Сохраняю…», «Контакт не найден» |
| `canvas.json` | Как экраны разложены на холсте |

Пример во всех макетах: сегодня 31 октября 2026, последняя заметка о Петре Соколове - 16 сентября 2026.

Цвета взяты из `src/app/globals.css`: красный `#ff0032` (primary), тёмно-красный для текста `#d6002a` (destructive), серый фон `#f2f3f7` (muted), серый текст `#626c77` (muted-foreground). Выбранная частота на макетах тёмная `#1d2023`, красный вариант включается в настройках макета (Tweaks).
