# Spec Delta

## MODIFIED Requirements

### Requirement: Название группы не повторяется

У одного пользователя двух групп с одинаковым названием SHALL не быть; регистр букв не различается: «Семья» и «семья» - одно название. Если при создании из карточки у пользователя уже есть группа с таким названием, новая MUST не создаваться: контакт добавляется в существующую. У разных пользователей группы с одинаковым названием SHALL уживаться независимо друг от друга.

#### Scenario: Создал группу с уже занятым названием
- **WHEN** группа «Семья» есть, и пользователь в карточке Бориса создаёт группу «семья»
- **THEN** окно закрылось, группа «Семья» по-прежнему одна, новой группы нет
- **AND** в карточке Бориса выделена «Семья»

#### Scenario: У A и B по группе «Друзья»
- **WHEN** у A есть группа «Друзья», и B в карточке своего контакта создаёт группу «Друзья»
- **THEN** у B создана своя группа «Друзья», его контакт в ней
- **AND** группа «Друзья» у A не изменилась, контакт B в неё не попал

#### Scenario: Переименование в название чужой группы
- **WHEN** у A есть группа «Друзья», и B переименовывает свою группу «Приятели» в «Друзья»
- **THEN** группа B называется «Друзья», ошибки «Такая группа уже есть» нет
