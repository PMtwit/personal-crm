# Spec Delta

## ADDED Requirements

### Requirement: «Скоро день рождения» - только свои

Блок «Скоро день рождения» SHALL показывать только контакты вошедшего пользователя. Дата рождения чужого контакта не видна и не меняется: запрос с номером чужого контакта отвечает «Контакт не найден», как для любого другого поля.

#### Scenario: День рождения у контакта A
- **WHEN** у контакта A день рождения завтра, а у контактов B в ближайшие 7 дней нет
- **THEN** у B на главной нет блока «Скоро день рождения»

#### Scenario: Дата рождения чужого контакта
- **WHEN** B отправил на сервер изменение контакта A с новой датой рождения
- **THEN** ответ «Контакт не найден», дата рождения контакта A не изменилась
